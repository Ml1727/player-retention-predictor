# Player Retention Predictor

An interactive machine learning web application that predicts whether a player is likely to continue playing a game based on gameplay behavior and engagement metrics.

## Features

* Predicts player retention using machine learning
* Interactive web interface using Streamlit
* Gameplay behavior analytics
* Real-time prediction system
* Data visualization and engagement analysis

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Matplotlib

## How It Works

The system analyzes gameplay behavior such as:

* Session length
* Levels completed
* Death count
* In-game purchases

The trained machine learning model predicts whether a player is likely to stay engaged or churn.

## Run Locally

Install dependencies:

```bash
pip install pandas numpy scikit-learn matplotlib streamlit
```

Run the application:

```bash
streamlit run app.py
```

## Project Goal

This project demonstrates machine learning fundamentals, behavioral analytics, and gaming data analysis concepts commonly used in recommendation systems and player engagement platforms.
