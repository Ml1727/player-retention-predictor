# Player Retention Prediction System

Machine learning project that predicts whether players will continue playing a game based on gameplay behavior data.

## Features

* Gameplay behavior analysis
* Player retention prediction
* Data visualization
* Machine learning classification

## Tech Stack

* Python
* Pandas
* Scikit-learn
* Matplotlib

## Goal

Analyze gameplay telemetry data to predict player churn and retention trends similar to modern gaming analytics systems.
